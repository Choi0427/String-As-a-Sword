# 밸런스 목표 (2026-11-19 합의)

수치 검증은 이 표에 대한 합격/불합격으로 판정한다. 실력 단계는 `SkillProfile`(완벽/고수/중수/초보) 프리셋, 측정 근거는 [Battle9Balance.md](Battle9Balance.md).

**기준 플레이어는 중수다.** 템포는 중수에 맞추고, 고수가 일찍 끝내는 것은 보상으로 본다.

| 지표 | 목표 | 이유 |
| --- | --- | --- |
| 중수 무력화 노트 중앙값 | 250–285 | 3단계(노트 234~) 채보를 보고, 마무리(303) 전 여유 18–50노트 |
| 클리어율 (전략 5종 평균) | 고수 ≥95%, 중수 70–85%, 초보 30–50% | 난이도 곡선 |
| 공명당 피해 고수/초보 | ≥1.4 | 정확도가 피해로 이어져야 한다 |
| 단계별 전략 격차 (최선−최악) | 5–15%p, 30%p 이상 금지 | 0이면 선택이 무의미, 크면 지배 전략 |
| 급변 | 보스 HP ±10%에서 중수 클리어율 변화 ≤15%p | 플레이어 편차에 너무 민감한 값 배제 |

모두 동시에 만족하는 조합이 없으면 우선순위는 중수 클리어율 > 무력화 노트 > 고수 클리어율 > 피해 격차 > 전략 격차 > 초보 순이다. 초보 클리어율은 플레이어 HP로 맞출 항목이라 미달이면 보고만 한다.

## 고정 순서

1. 공명 길이 (구조)
2. 공명 피해 Perfect/Good/카덴스 (실력 표현)
3. 공명 밖 피해 (루프 강제 여부)
4. 보스 HP (템포)
5. 플레이어 HP (생존, 사람 플레이테스트 후)

각 후보는 **동일 템포**로 비교한다. 후보마다 보스 HP를 다시 맞춰 중수 무력화 노트 중앙값을 268로 맞춘 뒤 지표를 잰다. 피해 단위와 HP는 비율만 의미가 있으므로 HP는 항상 마지막에 맞춘다.

## 아직 가정인 것

실력 프리셋(타이밍 오차 σ, 누락, 예고 못 읽음)은 가정값이다. 플레이테스트 판정 로그로 보정한 뒤 단계별 숫자를 다시 판정한다.
