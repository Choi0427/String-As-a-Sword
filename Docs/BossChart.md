# 보스 채보

보스의 공격을 곡의 노트 번호에 맞춰 텍스트 파일 하나에 직접 적는 방식이에요. 채보를 연결하면 랜덤 패턴(`Patterns`, `Attack Schedule`) 대신 채보대로 공격해요. 매 판 같은 노트에 같은 공격이 나와요.

- 채보 파일: `Assets/_Project/Data/Bosses/GeomEulHyeon.bosschart.txt` (시작용 예시)
- 코드: `Scripts/Combat/BossChart.cs`(파서), `BossPatternSystem`의 채보 모드, `Editor/BossChartValidator.cs`(검증기)

## 쓰는 법

`#` 뒤는 주석이에요. 빈 줄은 무시해요.

### 구간

```
section 후렴 97-140
```

검증 보고서에 `노트 120 [후렴]`처럼 이름이 붙어요. 게임 동작에는 영향이 없어요.

### 모양

```
shape X
20000002
02000020
00100100
00011000
00011000
00100100
02000020
20000002
```

- 8줄 × 8칸이고, 첫 줄이 판의 맨 윗줄(플레이어가 시작하는 줄)이에요.
- `0` = 공격 없음, `1` = 일반 공격(가드하거나 피함), `2` = 강공격(가드하면 가드가 깨지고 맞아요. 피해야 해요).
- 판 전체가 `1`이면 피할 칸이 없으니 **가드 전용** 공격이에요. 판 전체가 `2`면 막을 수도 피할 수도 없어서 오류예요.
- `shape 십자 anchor=4,4`처럼 `anchor=줄,칸`(1부터 셈)을 붙이면, 공격을 보여주는 순간 그 칸이 플레이어 위치에 오도록 모양이 옮겨져요. 판 밖으로 나간 칸은 잘려요.

### 공격

```
# 노트  모양  경고  [hits=연타수 every=간격]  [phase>=페이즈]
120     X     3
130     X     3     hits=4 every=2
200     X     2                       phase>=3
```

| 항목 | 뜻 | 범위 |
|---|---|---|
| 노트 | 첫 타격이 떨어지는 노트 번호 (0부터) | 곡 노트 수 미만 |
| 경고 | 몇 노트 전에 보여줄지. `노트 - 경고`가 닫히는 순간 보여줘요 | 1~5 |
| hits, every | 같은 모양을 `every` 노트 간격으로 `hits`번 연타 | 1~8, 1~4 |
| phase>=N | 보여주는 순간 보스 페이즈가 N 이상일 때만 공격하고, 아니면 건너뛰어요 | 1~4 |

- 페이즈가 바뀌어도 이미 보여준 공격은 취소되지 않아요. 피날레에서 보스가 스턴되면 모두 사라져요.
- 모양은 파일 어디에 정의해도 돼요. 공격 줄보다 아래에 있어도 괜찮아요.

## 스테이지에 연결

`Assets/_Project/Data/Stages/FourPhasePrototype.asset`의 **Boss Chart** 칸에 채보 파일을 끌어다 놓아요. 비우면 다시 랜덤 패턴으로 돌아가요. 규칙이 바뀌는 것이므로 연결할 때 `Combat Version`을 `battle-7`로 올려 주세요.

## 검증

Unity 메뉴 **String As a Sword → Boss Chart**에서 실행해요.

- **Validate**: 채보를 검사해요. Project 창에서 `.bosschart.txt`를 선택했으면 그 파일을, 아니면 기본 채보를 검사해요.
- **Validate and Simulate (200 seeds)**: 검사를 통과하면 이어서 봇 시뮬레이션을 돌려요. 클리어율, 공격·이동·방어 비율, 남은 노트를 기존 기준과 함께 보여줘요. 몇 분 걸려요.

결과는 `Docs/BossChart/validation.txt`에 저장돼요(시뮬레이션은 `Docs/BossChart/sim/`).

### 실패로 보는 것

| 검사 | 기준 |
|---|---|
| 범위 | 경고가 곡 시작 전에 시작하거나, 마지막 타격이 곡 노트 수를 넘음 |
| 빠른 구간 | 경고부터 마지막 타격까지 사이에 한 박(0.69초)보다 짧은 노트 간격이 있음 |
| 피할 길 | 판 **64칸 어디에서 출발해도** 경고 안에 피할 수 있어야 해요. 일반(`1`) 칸도 랜덤 패턴과 같이 피할 길이 있어야 하고, 가드 전용 공격만 이 검사를 건너뛰어요. 연타는 앞 타격과 그때 떠 있는 다른 공격까지 피하는 길로 검사해요 |
| 안전 칸 보호 | 먼저 보여준 공격이 끝나기 전(또는 같은 노트)에, 그 공격이 안전하다고 보여준 칸을 새 공격이 때림 |

### 경고만 하는 것

- 피날레 노트 이후의 공격: 보스가 스턴되면 나오지 않아요.
- 같은 노트에 공격 두 개.

보고서의 칸 표기 `(줄,칸)`은 그림과 같은 기준이에요. 위에서 몇 번째 줄, 왼쪽에서 몇 번째 칸이에요.

### 근사인 부분

`anchor` 모양이 다른 공격과 동시에 떠 있으면, 다른 공격의 위치를 같은 출발 칸 기준으로 계산해요. 실제로는 그 공격을 보여줄 때 플레이어가 다른 곳에 있었을 수 있어요. 이런 겹침은 봇 시뮬레이션으로 한 번 더 확인해 주세요.

## 배치 모드

```
Unity.exe -batchmode -quit -projectPath <프로젝트> -executeMethod StringAsASword.Editor.BossChartValidator.RunFromCommandLine [-bossChart 경로] [-bossChartSeeds 200] [-bossChartOutput Docs/BossChart]
```

채보가 실패하면 종료 코드 1로 끝나요. 에디터가 열려 있으면 배치 모드가 같은 프로젝트를 열 수 없어요.
